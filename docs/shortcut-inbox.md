# iPhone 공유 시트 → 스위티홈 수집함 단축어

카카오톡·인스타그램·노션 등에서 링크를 공유하면 스위티홈 앱을 열지 않고 수집함의 `신규` 메모로 보냅니다.

## 먼저 준비할 것

1. Vercel 프로젝트의 **Settings → Environment Variables**에서 `INGEST_TOKEN`을 추가합니다.
2. 값에는 충분히 길고 임의로 만든 비밀 문자열을 사용하고 Production 환경에 적용합니다.
3. 재배포가 끝난 뒤 아래 단축어의 `<INGEST_TOKEN>` 자리에 같은 값을 넣습니다.

`INGEST_TOKEN`은 비밀번호처럼 취급합니다. 화면 캡처·메신저·공개 문서에 남기지 말고, 유출이 의심되면 Vercel 값을 새로 바꾼 뒤 단축어도 갱신합니다.

## 단축어 만들기

1. iPhone의 **단축어** 앱에서 `+`를 눌러 새 단축어를 만듭니다.
2. 상단 이름을 `스위티홈에 담기`로 바꿉니다.
3. 상세 설정에서 **공유 시트에서 보기**를 켭니다.
4. 공유 시트 입력 유형은 **URL**만 선택합니다.
5. 첫 동작으로 **입력 요청**을 추가합니다.
   - 질문: `메모를 덧붙일까요?`
   - 입력 유형: 텍스트
   - 기본 답변: 비워 둠
6. 다음 동작으로 **URL 내용 가져오기**를 추가합니다.
7. URL에는 아래 주소를 입력합니다.

   ```text
   https://sweetyhome.vercel.app/api/ingest
   ```

8. **더 보기**를 열고 다음처럼 설정합니다.
   - 방법: `POST`
   - 요청 본문: `JSON`
   - 새 필드 `url`: 변수 **단축어 입력**
   - 새 필드 `memo`: 변수 **입력 요청의 결과**
9. 헤더를 두 개 추가합니다.
   - `Authorization`: `Bearer <INGEST_TOKEN>`
   - `Content-Type`: `application/json`
10. 마지막 동작으로 **알림 보기**를 추가하고 문구를 `스위티홈 수집함에 담았어요`로 정합니다.
11. 완료를 눌러 저장합니다.

## 사용 방법

1. 링크가 있는 앱에서 **공유**를 누릅니다.
2. 공유 시트에서 **스위티홈에 담기**를 선택합니다.
3. 필요한 경우 메모를 입력하고, 없으면 빈 채로 완료합니다.
4. 다음에 스위티홈을 열면 링크가 수집함의 `신규` 항목으로 들어옵니다.

전송 직후 앱에 바로 보이지 않아도 링크는 서버 인박스에 남아 있습니다. 스위티홈이 온라인 상태로 열리고 기존 데이터 저장까지 확인된 뒤에만 인박스에서 제거됩니다.

## 문제가 생길 때

- `401` 또는 인증 오류: Vercel의 `INGEST_TOKEN`과 단축어 헤더 값이 같은지, `Bearer ` 뒤에 공백 하나가 있는지 확인합니다.
- `413`: 메모가 너무 깁니다. URL과 메모를 합친 요청은 8KB 이하여야 합니다.
- `429`: 한 시간 호출 한도에 도달했거나 인박스가 100건 찼습니다. 잠시 뒤 다시 시도하거나 스위티홈 앱을 열어 먼저 수집합니다.
- 완료 알림은 떴지만 카드가 안 보임: 인터넷 연결을 확인한 뒤 스위티홈을 다시 엽니다. 서버에 남은 항목은 다음 로드 때 다시 병합을 시도합니다.
